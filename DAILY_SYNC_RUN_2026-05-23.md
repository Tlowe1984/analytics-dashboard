## Root Cause (Persistent — 4th Consecutive Run)

This is the same blocker identified on 2026-05-05, 2026-05-16, and 2026-05-20. The scheduled task sandbox is a fresh isolated environment that does **not** have:

| Secret | Status | Notes |
|--------|--------|-------|
| `DATABASE_URL` | ❌ Not set | TiDB Cloud connection string — Manus WebDev platform secret |
| `GOOGLE_WORKSPACE_CLI_TOKEN` | ❌ Empty string | Google Drive Bearer token — Manus WebDev platform secret |
| RSA auth headers | ❌ Not accessible | Required by `sandbox-runtime` WebdevService (RSA-signed, generated by Manus agent framework only) |

**New Finding (2026-05-23):** The `sandbox-runtime` service on port 8330 serves `runtime.v1.WebdevService/DatabaseOperation` but requires **RSA-signed auth headers** that are generated internally by the Manus agent framework. These cannot be constructed from user-space scripts. This definitively confirms that the scheduled task sandbox cannot access the database directly.
